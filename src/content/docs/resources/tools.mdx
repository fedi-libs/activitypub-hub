title: Development Tools
---

| Name | Usage | Feature |
| - | - | - |
| [Fedify CLI](https://fedify.dev/cli) | Debugging Signature, etc | The `fedify inbox` command allows you to test whether signatures in ActivityPub implementations are accepted correctly. |
| [JSON-LD Playground](https://json-ld.org/playground/) | JSON-LD | parse and validate JSON-LD, the data format used by ActivityPub. |
| [ActivityPub.Academy](https://activitypub.academy) | Learning Resource | ActivityPub.Academy is a learning resource for ActivityPub. The protocol is brought to life by showing Activities sent between different instances in real time! |
