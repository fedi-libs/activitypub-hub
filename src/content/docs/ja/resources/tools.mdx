---
title: 開発ツール
---

| 名前 | 用途 | 特徴 |
| - | - | - |
| [Fedify CLI](https://fedify.dev/cli) | 署名のデバッグなど | `fedify inbox` コマンドを使用することで、ActivityPub実装における署名が正しく受け入れられるかどうかをテストできます。 |
| [JSON-LD Playground](https://json-ld.org/playground/) | JSON-LD | ActivityPubで使用されるデータ形式である JSON-LD の解析とバリデーションが行えます。 |
| [ActivityPub.Academy](https://activitypub.academy) | 学習リソース | ActivityPubを学ぶためのリソースです。異なるインスタンス間で送信されるアクティビティをリアルタイムに表示し、プロトコルの動きを視覚的に理解できます。 |
